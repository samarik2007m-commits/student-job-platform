# StudentJob Platform

Production-ready MVP for a student recruitment marketplace with monetization, multi-role access, Stripe-ready billing, and deploy-ready setup.

## Features
- Student and employer registration
- Admin role and dashboard
- Job catalog with filters and categories
- Applications and applicant management
- Subscription plans and pricing grid
- SQLite database for persistent data
- Stripe-ready checkout flow with demo fallback
- Docker and Render configuration for deployment

## Local development

Backend:
```bash
cd backend
cp ../.env.example .env
npm install
npm run dev
```

Frontend:
```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

Open http://localhost:5173

## Production notes
- Uses SQLite for simple persistence without external DB host.
- Stripe is integrated but disabled unless STRIPE_SECRET_KEY is set.
- Render config is included for one-click backend/frontend deployment.

## Deployment

### Render
1. Connect the repo to Render.
2. Use the included render.yaml.
3. Add your real backend/frontend URLs in env vars.
4. Set STRIPE_SECRET_KEY for actual payments.

### Docker
```bash
docker compose up --build
```
